# Vertical Slice Scope

## Included

- Gardun city gray-box
- 16–24-player design target
- Two fictional factions
- Two infantry classes per faction
- KR-47 fictional rifle plus three later fictional primaries
- Nomad transport
- Warden tank
- Falcon helicopter
- Stronghold Assault
- One server-controlled surprise event per match
- Progression and cosmetic Command Tokens
- Dedicated authoritative server
- Cloudflare gateway, R2 assets, Queue jobs, and admin skeleton

## Excluded

- Real militant organizations or commanders
- Real attack reconstruction
- Open world
- Blockchain
- Marketplace trading
- Ranked esports
- Jets and naval warfare
- Universal destruction
- Console and mobile release
